# Simulador de Autómatas

Proyecto final del curso:

**Autómatas y Lenguajes Formales**

## Descripción

Aplicación desarrollada en Python para crear y simular autómatas finitos.

Permite trabajar con:

- AFN
- AFD
- Transiciones con ε
- Simulación de cadenas
- Conversión AFN → AFD
- Minimización de AFD

## Tecnologías

- Python
- Tkinter
- Git/GitHub
